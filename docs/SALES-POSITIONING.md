# Sales Positioning Guardrails

## Strongest message

> Claude Code를 계속 사용하면서 GitHub Copilot entitlement와 governance 아래의 Claude model을 선택할 수 있는 compatibility path.

GitHub Copilot sales에는 직접적인 가치가 있습니다.

- 기존 Claude Code workflow 유지
- 별도 Anthropic subscription 없이 Copilot plan과 policy 사용
- GitHub Copilot model catalog와 AI Credits 적용
- organization model policy와 user identity 적용

## Azure message

Azure 가치는 model availability 주장보다 운영 계층에 연결해야 합니다.

- Azure Container Apps 또는 AKS에 enterprise bridge 배포
- Microsoft Entra 기반 사용자 접근 제어
- Azure Key Vault credential handling
- Application Insights와 Azure Monitor observability
- Private networking과 policy enforcement

## 피해야 할 표현

- “Azure Foundry에서 한국 지역 Claude model을 제공한다”
- “GitHub와 Anthropic이 공식 지원하는 integration이다”
- “Claude Code의 모든 기능이 완전 호환된다”
- “Copilot subscription으로 무제한 Claude API를 제공한다”

현재 단계의 정확한 표현은 **working prototype / technical preview candidate**입니다.
